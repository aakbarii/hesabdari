# JooJoo mascot assets

Generated with the built-in imagegen tool; optimized to transparent WebP for this app.

- wave.webp: Original butter-yellow fluffy baby chick, chubby body, kind dark eyes, rosy cheeks, large pink satin head bow, waving while holding a pink heart. Premium soft 3D plush illustration, isolated transparent background, no text.
- cozy.webp: Same referenced character sitting peacefully, eyes closed, hugging a lavender heart pillow. Preserve bow, plumage, proportions and rendering; transparent background, no text.

Both are original generated assets. The project uses local files and no external image service at runtime.

## Logo and install icons

Built-in imagegen edit using wave.webp as identity reference: close-up chick face and upper chest, preserve yellow fluffy plumage and pink satin bow, large readable eyes, opaque strawberry-milk pink square with cream halo, no text or device mockup; keep character inside central 75% safe area. Optimized exports: logo.webp, icon-32.png, icon-180.png, icon-192.png, icon-512.png. The JooJoo manifest retains the same app id and scope.
